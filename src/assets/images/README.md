# 图片占位素材说明

本目录中的 SVG 全部是为页面布局准备的抽象占位图，不代表任何真实人物、学校、公司或项目。发布前必须替换为你拥有使用权的真实素材。

## 文件用途

- `portrait-placeholder.svg`：首屏人物照片占位，不包含人物肖像。建议替换为透明背景 PNG/WebP，画面以半身或全身人物为主。
- `project-placeholder-01.svg` 至 `project-placeholder-04.svg`：四个项目封面占位。建议使用统一宽高比的项目截图、作品照片或经过授权的视觉素材。
- `education-placeholder-01.svg`、`education-placeholder-02.svg`：两段教育经历图片占位，不对应任何真实校园。

## 推荐替换规格

| 用途 | 推荐尺寸 | 推荐格式 | 注意事项 |
| --- | --- | --- | --- |
| 人物图 | 至少 1200 × 1500 px | 透明 WebP 或 PNG | 只使用本人或已获授权照片，保留自然边缘 |
| 项目封面 | 至少 1600 × 960 px | WebP 或 AVIF | 四张图保持统一色调，避免嵌入过小正文 |
| 教育图片 | 至少 1600 × 960 px | WebP 或 AVIF | 确认校园照片版权与隐私信息 |

可直接用同名文件替换占位图，也可以修改 `src/data/profile.js` 中的导入路径。替换后请同步更新对应 `imageAlt`，准确描述图片内容；不要在替换前删除“待补充”提示，以免占位信息被误认为真实履历。
